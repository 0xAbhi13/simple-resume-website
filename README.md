## 📝 My Approach

1. **Read the brief first:** single-page resume, HTML5 + CSS3 only, semantic markup, responsive layout, honest content (no invented contact details, experience, or stats).
2. **Verified real data:** used only verified public links — portfolio, LinkedIn, GitHub, tribute-page (live + repo), and personal-introduction-page (live + repo). Descriptions match what each project actually is.
3. **Built mobile-up:** semantic landmarks, single `h1`, CSS custom properties for the white / dark-navy / electric-blue theme, Flexbox for components, Grid for hero/skills/projects, two breakpoints (920px, 680px), CSS-only checkbox hamburger menu — no JavaScript needed.
4. **Made the download real:** generated a valid `resume.pdf` with the same resume content and added a `@media print` stylesheet, so both the button and `Ctrl+P → Save as PDF` produce a clean resume.
5. **Tested honestly:** static checks (HTML structure, link targets, CSS tokens, PDF validity) plus a local serve test; fixed failures before submitting.

## 🌐 Deployment

**GitHub Pages:**

```powershell
git init -b main
git add index.html style.css resume.pdf README.md vercel.json .gitignore assets
git commit -m "Day 3: Simple Resume Website (HTML + CSS)"
git remote add origin https://github.com/0xAbhi13/internship-task-3.git
git push -u origin main
```

Then GitHub → **Settings → Pages → Deploy from a branch → `main` / root** → `https://0xabhi13.github.io/internship-task-3/`

**Vercel:** Import `internship-task-3`, preset **Other**, no build command, no env vars.
